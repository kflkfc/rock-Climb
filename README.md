# 硬核抱石模拟器 · Boulder Sim

让普通人在手机/浏览器上体会真实抱石的爽快与脑力博弈。参考冰岛网页游戏 **Klifur** 的"四肢独立操作 + 重心平衡"机制，叠加真实岩点种类、抓法匹配、耐力系统，做成一款硬核抱石模拟器。

> 当前为**核心垂直切片（技术验证 Demo）**：1 面直壁 + 1 条 V0 路线，跑通完整核心闭环，用于验证物理与操作手感。

🎮 **在线试玩**：https://kflkfc.github.io/rock-Climb/ （首次推送后由 GitHub Actions 自动部署，约 1-2 分钟生效）

## 玩法（V4 接触式拖拽 + 耐力匹配）

设计经 4 次迭代定稿为纯拖拽方案（淘汰了早期双摇杆）：

```
拖动角色身上的彩色把手（肢端）→ 接触岩点即锁定 → 在岩点上微调找甜点
→ 松手弹出抓法环（每个抓法显示匹配度 %）→ 选抓法 → 开始消耗耐力
```

- **四肢独立**：左手(粉) / 右手(紫) / 左脚(绿) / 右脚(橙)，逐个挪到更高岩点向上攀爬
- **重心平衡**：重心 X 必须落在抓点支撑跨度内，否则失衡 → 脱手
- **耐力匹配**：匹配度越高越省力；错误抓法不立即脱手，而是耐力急耗（教学性强）
- **Jug 大水罐**跳过抓法环直接抓住；**Crimp/Pinch/Sloper** 需选抓法
- 脱手掉落会**自动复位起点**（失败成本低），手抓到顶部彩虹终点 → 完攀，含 3 秒回放定格
- 评分：抓取次数 ✋ + 星级 ⭐ + 用时 ⏱

右上角有**调参面板**（重力/抓力/耐力/手感等实时滑块），应对物理调参。

## 快速开始

```bash
cd BoulderSim
npm install
npm run dev      # 浏览器打开 http://localhost:5173
```

其他命令：

```bash
npm run test     # Vitest 单元 + 集成测试
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览生产构建
```

## 技术架构

**TypeScript + Canvas 2D + Vite**。核心原则：**物理逻辑与渲染彻底解耦**，`core/` 为纯逻辑零 DOM，可整体移植到 Unity / Cocos / 微信小程序。

```
BoulderSim/
├── src/
│   ├── core/                # ★ 纯逻辑（无 DOM，可移植）
│   │   ├── math/            # 向量、2-骨解析 IK
│   │   ├── model/           # 11 段骨骼姿态、人体参数
│   │   ├── sim/             # 岩点、抓法匹配度、物理(力分解/平衡/脱手)、耐力、状态机
│   │   └── level/           # 关卡数据格式 + V0 关卡
│   ├── render/              # 渲染层（只读 core 状态）：墙/岩点/角色/HUD/抓法环/耐力环/特效/姿态平滑
│   ├── input/               # 指针/触屏 V4 交互
│   ├── audio/               # 音效 + 振动反馈
│   └── config/              # 全部物理常数（调参面板）
└── tests/                   # 物理核心 + V4 交互闭环测试
```

核心机制实现位置：

| 机制 | 文件 |
|---|---|
| 匹配度公式 | `core/sim/grip.ts` |
| 力分解 / 抓力上限 / 平衡 / 脱手 | `core/sim/physics.ts` |
| 骨盆跟随攀爬（挂手/撑脚） | `core/sim/physics.ts` · `solvePelvis` |
| 状态机 + V4 交互编排 | `core/sim/gameState.ts` |
| 解剖学正确的关节弯曲 | `core/model/skeleton.ts` |
| 动作平滑（防瞬移/反关节） | `render/poseSmoother.ts` |
